# deep-seek-test

Мой первый пробный проект на GitHub.

## Что это

Простая веб-страница: заголовок, кнопка-счётчик нажатий и приветствие.

## Файлы

- `index.html` — разметка страницы
- `style.css` — стили (градиентный фон, кнопка)
- `script.js` — логика счётчика нажатий

## Демо

Сайт опубликован через GitHub Pages:
https://kakuleshov.github.io/deep-seek-test/

## Как запустить локально

1. Скачайте файлы `index.html`, `style.css`, `script.js` в одну папку.
2. Откройте `index.html` двойным кликом в браузере.

## Технологии

- HTML
- CSS
- JavaScript (без фреймворков)

## Структура

- `index.html` — главная
- `about.html` — о проекте
- `contact.html` — контакты
- `404.html` — страница ошибки
- `style.css` — стили
- `script.js` — счётчик
- `robots.txt`, `sitemap.xml` — для поисковиков
- `favicon.svg` — иконка
- `LICENSE` — лицензия MIT
